# 🤖 Astra AI Assistant — Interactive Preview & Mobile APK

Welcome to the interactive preview release of the **Astra AI Assistant**. This repository serves as a standalone showcase of Astra's design systems, multi-modal pipelines, smart-home features, and includes the native Android client package.

---

## 🌟 Try It Out (Live Online)

You can view and interact with the Astra presentation HUD directly in your web browser!

🔗 **[Open Interactive Live Demo (GitHub Pages)](https://Future-Web2.github.io/Astra-AI-Assistent-Preview/)**
*(Note: To test the voice commands, enable GitHub Pages in your repository Settings -> Pages, select the `main` branch, and open the generated link).*

### Features of the Web Preview:
*   **🎙️ Speak to Astra (Browser-Native):** Click the microphone button in the HUD input panel, speak a command (e.g. *"open notepad"*, *"write code"*, *"theme sunset"*, *"help"*), and Astra will transcribe your voice and **speak back** to you in the selected language!
*   **🏠 Smart Home Simulator ("THE FUTURES"):** Click to toggle rooms (Living Room, Kitchen, Bedroom, Garage) and witness real-time feedback in the AstraOS process monitor.
*   **🎨 Dynamic Themes:** Switch between **Aurora**, **Cyberpunk**, and **Sunset** styling variables in the header to alter the entire page's aesthetics.
*   **📊 Integrated Tech Stack:** Click stack items to see exactly how Electron, Flask, Java, io.net, and Speech APIs operate.

---

## 📱 Native Android Client (APK)

Test the native Android experience on your mobile device!

📦 **[Download Android APK (app-debug.apk)](https://github.com/Future-Web2/Astra-AI-Assistent-Preview/raw/main/app-debug.apk)**

### Android Features:
*   **AstraOrbView:** Custom Java Canvas drawing the 14x14 pixel-art smiling face.
*   **PixelParticlesView:** Parallax drifting backgrounds utilizing your device's rotational gyro sensors.
*   **Dict Programmatic Switcher:** Dynamic language changes on-the-fly.
*   **ThemeManager:** Adaptive layout styling matching CSS design tokens.

## 💻 Running Locally

To run the web preview locally:
1.  Clone this repository:
    ```bash
    git clone https://github.com/Future-Web2/Astra-AI-Assistent-Preview.git
    ```
2.  Open `index.html` in any web browser.
